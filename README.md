# Toko Online Zokent Group
Aplikasi web manajemen toko dan kasir.

## Alur Sistem & Halaman (Page Flow)
- **Halaman Toko (`index.html`):** Tempat pelanggan melihat katalog produk, memilih barang, dan membuat pesanan.
- **Sistem Pembayaran:** Terhubung dengan integrasi QRIS/DANA untuk *checkout*.
- **Halaman Admin & Kasir:** Digunakan untuk mengelola inventaris barang, memantau transaksi, dan rekap laporan.
